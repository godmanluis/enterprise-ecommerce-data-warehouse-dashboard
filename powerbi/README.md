# Power BI Project README

This folder contains the dashboard logic and documentation for the executive reporting layer.

## Dashboard Objectives

- summarize performance trends
- uncover margin leakage
- support executive communication
- make analytics available without manual spreadsheet work

## Main Dashboard Views

- Overview
- Region Performance
- Product Profitability
- Logistics Cost Analysis
- Return and Fulfillment Analysis

## Notes

The full `.pbix` file is not included in this repository by default. This project package focuses on the warehouse design, documentation, SQL scripts, and DAX logic needed to reproduce the analytics work.
